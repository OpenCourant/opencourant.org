## About the Event

Join us for an exciting day of discussions, demonstrations, and information-sharing about the use of MFront. Whether you are a researcher, engineer, software developer, or simply interested in the possibilities of materials modeling, this event is an opportunity to learn more about MFront, ask questions directly to the developers, engage with fellow users, and explore how it can be integrated into your modeling projects.

The following talks are already announced :

- Overview of `TFEL-5.2` and `MGIS-3.2`

- Efficient multiscale simulation of an industrial fiber-reinforced composite using pre-computed morphological tensors

- Alternative methods for the calibration of the Drucker-Prager/Cap model, application to the MOX fuel shaping

- Application of MANTA to the description of brittle fracture.

- Developping new interfaces for `ElmerFEM` and the explicit dynamics code `OpenCourant`/`(Open)Radioss`

- Simulation of Static Strain Ageing and prediction of its impact on the fracture toughness properties of C-Mn steel welds

- « D’AMITEX à AMITEX* : des microstructures aux structures simples »

- MFront interface with MANTA, an open source explicit implicit multiphysics solver for industry and research applications

- Implementation of Neural Network Constitutive Laws Inside MFront

- Open-source implementation of a flexible nonlocal scheme using MFront/OpenGeoSys

- The `TDLS` library: fast tiled linear solvers for implicit `MFront` behaviours

The abstracts are available here: https://github.com/thelfer/tfel-doc/blob/master/MFrontUserDays/TwelfthUserDay/Agenda/talks.md
